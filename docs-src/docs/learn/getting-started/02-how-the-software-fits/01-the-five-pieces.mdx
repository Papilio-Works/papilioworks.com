## Check yourself

   - a) FPGA-Companion
   - b) The FPGA core
   - c) Papilio Loader
2. You want to switch from the Atari 2600 core to the Commodore 64 core. Which piece does that?
   - a) FPGA-Companion's on-screen menu
   - b) Papilio Loader, through the Papilio ESP Bootloader
   - c) The ROM on the SD card
3. Which piece loads ROMs into the running core and passes your controller's buttons to it?
   - a) FPGA-Companion
   - b) The Papilio ESP Bootloader
   - c) Papilio Loader
